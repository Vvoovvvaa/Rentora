# Rentora 🏠

Rentora is a real estate marketplace platform designed for buying, selling, and managing properties.

The platform allows users to create accounts, publish property listings, manage real estate information, and search for available properties through a modern backend system.

## Features

- User authentication and authorization
- Property listings management
- Real estate information management
- User profiles
- Secure backend API

## Tech Stack

- NestJS
- TypeScript
- PostgreSQL
- TypeORM
- JWT
- Docker

## Goal

Rentora aims to simplify the process of finding and managing real estate by providing a scalable platform for users and property owners.
